Introduction

L'API CIQUAL donne accès à la base de données officielle de composition nutritionnelle des aliments de l'ANSES (version 2025), comprenant 3 484 aliments.

L'API est entièrement statique et hébergée sur GitHub Pages. Elle ne nécessite aucun serveur. Les données sont servies sous forme d'un fichier JSON unique que vous filtrez côté client.

BASE URL
https://wikimindai.github.io/ciqual-api
FORMAT
JSON
CORS
✓ Activé
AUTH
API Key (optionnel)

Authentification

L'endpoint principal /data.json est public et ne nécessite aucune authentification.

Pour les endpoints avancés (futurs), une clé API est requise. Passez-la via le paramètre api_key :

URL
https://wikimindai.github.io/ciqual-api/data.json?api_key=wm-fd12345678

Les clés sont de la forme wm-fd suivi de 8 chiffres aléatoires uniques. Elles sont stockées dans Firebase et vérifiables via l'endpoint /validate.

Valider une clé API

GET /validate?api_key={votre_clé}

Vérifie qu'une clé API existe et n'est pas expirée. Répond avec les métadonnées de la clé.

Réponse 200
{
  "valid": true,
  "key": "wm-fd12345678",
  "name": "Mon appli",
  "created_at": "2025-06-01T10:00:00Z",
  "expires_at": "2025-09-01T10:00:00Z"
}

Exemples d'intégration

JavaScript (Fetch API)

JavaScript
// Récupérer tous les aliments
const res = await fetch('https://wikimindai.github.io/ciqual-api/data.json');
const aliments = await res.json();

// Rechercher par nom
const results = aliments.filter(a =>
  a.names.fr.toLowerCase().includes('pomme')
);

// Filtrer par catégorie (fruits = groupe 2)
const fruits = aliments.filter(a =>
  a.categories.group_code === '2'
).slice(0, 10); // 10 premiers

Python

Python
import requests

url = "https://wikimindai.github.io/ciqual-api/data.json"
aliments = requests.get(url).json()

# Recherche par nom
resultats = [
    a for a in aliments
    if 'pomme' in a['names']['fr'].lower()
]
print(f"{len(resultats)} résultats trouvés")
for a in resultats[:3]:
    print(f"• {a['names']['fr']} (id: {a['id']})")

Avec authentification API

JavaScript
const API_KEY = 'wm-fd12345678'; // Votre clé

// Valider la clé avant d'appeler
async function validateKey(key) {
  const db = firebase.database();
  const snap = await db.ref(`api_keys/${key}`).once('value');
  return snap.exists() && !snap.val().expired;
}

// Appel sécurisé
const isValid = await validateKey(API_KEY);
if (isValid) {
  const data = await fetch(
    `https://wikimindai.github.io/ciqual-api/data.json`
  ).then(r => r.json());
  // Traitement...
}
